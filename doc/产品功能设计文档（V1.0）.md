# PaperLens 产品功能设计文档（V1.0）

> 版本：V1.0｜日期：2026-10-25
>
> 配套文档：`用户故事文档（V1.0）.md`
>
> 阅读提示：本文说明产品结构、页面、交互、对象和规则，供产品、设计、开发和 AI 实现者共同阅读。本文只写产品行为，不写接口、数据库字段和测试步骤。

## 0 一分钟看懂

PaperLens 由四个空间组成：

| 空间 | 作用 | 入口 |
| :--- | :--- | :--- |
| 全局论文目录 | 管理员维护的全部论文，是搜索的唯一来源 | 管理员后台；用户主页搜索 |
| 会话 | 一次查询得到的论文、证据和对话 | 主页查询后自动进入 |
| 仓库 | 用户从全局目录挑选的论文集合 | 主页“我的仓库”、会话“相关仓库” |
| 论文详情 | 单篇论文的元数据、四维、原文和单篇对话 | 任意论文标题、引用 |

三条主路径：

```text
主页查询/PDF → 全局 RAG → 会话（对话 / 论文总结 / 相关仓库）
仓库 → 左侧论文列表 + 右侧仓库对话
论文详情 → 四维 / 下载 / 单篇对话
```

**V1.0 不设论文数量、仓库容量、检索范围档位等数量限制。** 这些属于后续扩展，不进入本期 P0。

## 1 设计目标与原则

### 1.1 目标

让用户从“我有一个问题”走到“我有一组可读、可比较、可追溯的论文”，并能在会话、仓库和单篇三个层次继续追问。

### 1.2 设计原则

| 原则 | 含义 |
| :--- | :--- |
| 一个入口 | 主页只负责“查询”，不在主页堆仓库管理和筛选 |
| 三个视图 | 会话页固定为对话、论文总结、相关仓库，切换不丢状态 |
| 三个范围 | 会话、仓库、单篇三种对话严格隔离，避免模型越界 |
| 证据优先 | 回答先有证据，再生成文字；没有证据就拒答 |
| 论文级四维 | 四维属于论文，不属于会话；一次生成，多处复用 |
| 全局与仓库分离 | 全局目录决定“有什么论文”，仓库决定“我挑了哪些论文” |
| 私有只隐藏集合 | 私有仓库对普通用户隐藏集合和对话，不隐藏论文本身；管理员可管理私有仓库 |
| 不做上传 | 论文只由管理员导入；用户只能从全局目录挑选 |
| 不设数量限制 | 本期不写死论文数、仓库容量、证据数和范围档位 |

## 2 用户与权限

### 2.1 角色

| 角色 | 说明 |
| :--- | :--- |
| 游客 | 未登录访问者，只能看到登录页 |
| 普通用户（reader） | 搜索、会话、创建和管理自己的仓库、star 公开仓库、三种对话、下载 |
| 管理员（admin） | 普通用户能力 + 全局论文目录 + 用户管理 + 管理总览 + 私有仓库管理 |

账号由管理员创建，不开放自注册；V1.0 不做 SSO、LDAP、TOTP。

### 2.2 权限矩阵

| 操作 | 游客 | 普通用户 | 仓库创建者 | 管理员 |
| :--- | :---: | :---: | :---: | :---: |
| 登录、退出、查看当前用户 | 登录 | ✅ | ✅ | ✅ |
| 全局搜索、查看会话 | ❌ | ✅ | ✅ | ✅ |
| 查看全局论文详情、下载 | ❌ | ✅ | ✅ | ✅ |
| 创建仓库 | ❌ | ✅ | ✅ | ✅ |
| 查看公开仓库 | ❌ | ✅ | ✅ | ✅ |
| 编辑公开仓库 | ❌ | ❌ | ✅ | ❌ |
| 查看私有仓库 | ❌ | ❌ | ✅ | ✅ |
| 管理私有仓库（编辑、增删论文、删除） | ❌ | ❌ | ✅ | ✅ |
| star 公开仓库 | ❌ | ✅（非自己的） | ✅（非自己的） | ✅（非自己的） |
| 仓库对话 | ❌ | 公开仓库 | 自己的仓库 | 公开仓库；私有仓库（管理） |
| 单篇论文对话 | ❌ | ✅ | ✅ | ✅ |
| 导入论文、维护目录 | ❌ | ❌ | ❌ | ✅ |
| 管理用户、查看总览 | ❌ | ❌ | ❌ | ✅ |

> 表中的“管理员”列指不是仓库创建者的管理员；管理员如果自己创建仓库，按“仓库创建者”列处理。管理员可以管理私有仓库，但对公开仓库只读。

#### AUTH-03 角色与权限边界

- 权限在服务端判断；前端隐藏按钮不能代替权限判断。
- 无权访问时不返回资源名称、数量、创建者等元信息。
- 管理员可以查看和管理私有仓库的论文集合与对话；普通用户不能读取他人的私有内容。
- 公开仓库的编辑权只属于创建者；管理员对公开仓库只读。
- 公开仓库的他人对话只属于发起者，仓库创建者和其他用户看不到。
- 角色和管理员能力是产品权限，不涉及部署、审计或多租户。

## 4 信息架构

### 4.1 页面地图

| 路由 | 页面 | 角色 | 核心内容 |
| :--- | :--- | :--- | :--- |
| `/login` | 登录 | 全部 | 邮箱、密码、错误提示 |
| `/` | 主页 | 登录用户 | 查询框、PDF 查询、最近会话、我的仓库、公开仓库、管理入口 |
| `/sessions/:id` | 会话工作区 | 会话所属用户 | 对话、论文总结、相关仓库 |
| `/repos/:id` | 仓库页 | 公开仓库所有登录用户；私有仓库创建者、管理员 | 左论文列表、右仓库对话、star、编辑 |
| `/papers/:id` | 论文详情 | 登录用户 | 元数据、四维、原文/下载、单篇对话 |
| `/admin` | 管理总览 | 管理员 | 数量概览、快捷入口 |
| `/admin/papers` | 论文目录 | 管理员 | 导入、状态、元数据、重试、归档 |
| `/admin/repos` | 仓库管理 | 管理员 | 所有仓库（含私有）、查看、编辑和删除私有仓库 |
| `/admin/users` | 用户管理 | 管理员 | 创建、角色、停用、重置密码 |

### 4.2 导航结构

- 顶部导航：Logo、主页、我的仓库（下拉或入口）、管理后台（仅管理员）、用户菜单。
- 会话页：顶部返回主页；中间三个视图标签；右侧无全局侧栏。
- 仓库页：顶部返回；左侧论文列表；右侧可收起对话面板。
- 论文详情：顶部返回来源；主体信息；单篇对话入口。
- 管理后台：左侧导航（总览、论文目录、仓库管理、用户管理），顶部返回主页。
- 所有页面都保留当前用户和退出入口。

## 5 核心对象与关系

### 5.1 对象

| 对象 | 责任 | 关键关系 |
| :--- | :--- | :--- |
| 用户 | 账号、角色、状态 | 拥有仓库、会话、对话；可以 star 公开仓库 |
| 论文 | 全局目录中的一篇论文 | 被仓库引用；被会话引用；拥有四维缓存 |
| 论文文件 | 管理员导入的 PDF 和解析状态 | 属于论文；有处理状态和失败原因 |
| 原文片段 | 可检索、可引用的原文单位 | 属于论文；被会话证据引用 |
| 仓库 | 用户整理的论文集合 | 属于创建者；引用多篇论文；有公开/私有 |
| 仓库论文关系 | 仓库与论文的多对多关系 | 记录论文被加入仓库 |
| 会话 | 一次全局查询的结果空间 | 属于用户；保存论文和证据快照 |
| 会话证据 | 会话中保存的原文片段 | 引用论文片段；用于引用和对话 |
| 四维缓存 | 论文级四维总结 | 属于论文；按详略和版本缓存 |
| Star | 用户对公开仓库的推荐信号 | 用户与仓库的多对一关系 |
| 对话 | 一段有范围的聊天 | 属于用户；范围是会话、仓库或单篇论文 |
| 消息 | 对话中的一问一答 | 属于对话；保存引用 |

### 5.2 关系

```text
用户 1─N 仓库 1─N 仓库论文关系 N─1 论文
用户 1─N 会话 1─N 会话证据 N─1 原文片段 N─1 论文
论文 1─N 原文片段
论文 1─N 四维缓存
用户 N─M 仓库（Star）
用户 1─N 对话 1─N 消息
对话 → 会话 / 仓库 / 单篇论文
```

### 5.3 关键不变量

1. 论文是全局对象；仓库只引用论文，不复制论文。
2. 私有仓库对普通用户只隐藏集合和对话，不隐藏论文；管理员可管理私有仓库。
3. 会话保存查询时的论文和证据快照；后续全局查询不修改旧会话。
4. 四维按论文缓存，跨会话、仓库、详情共享；不按用户、不按会话重复生成。
5. Star 只属于公开仓库；私有仓库没有可见 star。
6. 论文默认归档而不是物理删除；归档不破坏旧会话和旧仓库的引用。
7. 首页 PDF 只查询，不入库、不进仓库。

## 6 页面设计

### 6.1 登录

页面元素：

- 产品名和一句话说明；
- 邮箱输入框；
- 密码输入框；
- 登录按钮；
- 错误提示区域。

交互：

- 提交后进入主页；失败只显示“邮箱或密码错误”。
- 没有自注册、忘记密码、SSO、LDAP、TOTP 入口。
- 未登录访问业务页面时回到登录页，不展示任何业务内容。

#### AUTH-01 登录

- 只支持本地账号密码；账号由管理员创建。
- 登录成功后建立登录状态；登录过期后回到登录页。
- 不区分“账号不存在”和“密码错误”，避免泄露账号信息。

#### AUTH-02 退出与当前用户

- 顶部用户菜单展示当前显示名和角色。
- 退出后清除登录状态，回到登录页。
- 刷新页面后仍能识别当前用户；过期或失效时回到登录页。
- 未登录用户看不到论文、仓库、会话和对话内容。

### 6.2 主页

主页是唯一查询入口，不做仓库筛选和论文筛选。

页面结构从上到下：

1. **顶部导航**：Logo、我的仓库、管理后台（仅管理员）、用户菜单。
2. **查询区**：标题、文字输入框、PDF 查询按钮、搜索按钮。
3. **结果提示**：检索进度、错误提示。
4. **最近会话**：查询词、时间、论文数量；点击重新打开。
5. **我的仓库**：仓库卡片、创建仓库按钮。
6. **公开仓库**：公开仓库卡片、star 数量；点击进入。

查询区的文案要点：

- 主标题表达“用一句话找到相关论文”；
- PDF 按钮旁明确写“仅用于本次查询，不会入库”；
- 不出现年份、期刊、类型等筛选控件；
- 不出现“选择仓库后再搜索”的控件；全局搜索就是全局目录。

状态：

- 初次进入：查询框为空，最近会话/仓库可能为空。
- 搜索中：按钮不可重复提交，显示检索进度。
- 搜索成功：自动进入会话页。
- 搜索无结果：进入会话空状态，提示修改查询。
- PDF 无法读取：停留主页，提示改用文字查询。
- 模型不可用：提示稍后重试，不创建空结果会话。

#### SRCH-01 主页文字/PDF 查询

- 文字查询支持研究方向、关键词、论文标题或一句自然语言问题。
- PDF 查询只提取文字，作为本次查询的输入；不保存文件、不入库、不加入仓库。
- 本期不做图片：图片型 PDF、扫描件、截图不解析，不做 OCR；只读取带文本层 PDF 的文字层。
- 全局查询范围是全部全局论文目录，不是用户自己的仓库集合。
- 提交后显示进度，成功后自动进入会话；失败或无结果时给出明确下一步。
- 主页不提供筛选和排序设置。
- 最近会话、我的仓库、公开仓库是主页的辅助入口，不与查询结果混在一起。

### 6.3 会话工作区

会话页是全局查询的结果空间，由顶部信息、三个视图和空状态组成。

顶部信息：

- 返回主页；
- 本次查询词；
- 范围标识“全局论文目录”；
- 相关论文数量、证据数量、相关仓库数量；
- 三个视图标签：对话、论文总结、相关仓库；
- “创建仓库”入口：可以新建空仓库，也可以把本次会话中的论文带入新仓库。

默认视图：

- 首次进入默认“对话”；
- 对话顶部有一条系统消息，概述本次找到了哪些论文；
- 系统消息提示“可以在论文总结里展开四维”。

视图切换：

- 切换不丢失对话输入、论文展开状态、仓库 star 状态；
- 不重新发起检索；
- 不改变会话证据。

空状态：

- 没有相关证据时，三个视图都显示空状态；
- 对话输入不可用；
- 提供“修改查询”“去仓库看看”两个入口；
- 不生成四维，不显示伪造的论文。

#### SRCH-02 全局 RAG 与会话创建

- 系统从全局论文目录检索相关论文和原文证据。
- 一次查询创建一个会话，保存查询、论文、证据和时间。
- 不设固定论文数量、证据数量或范围档位；按相关性和可用上下文组织结果。
- 检索成功后自动进入会话；没有结果也创建空会话。
- 四维不阻塞会话创建；进入会话后按需生成。
- 会话属于发起用户；重新打开时使用保存的证据快照。
- 会话不因为全局目录后续新增论文而自动变化。

#### SRCH-03 会话工作区三视图

- 三个视图固定为：对话、论文总结、相关仓库。
- 对话：围绕本次证据提问；不重新检索。
- 论文总结：本次会话涉及的论文，一行一篇，可展开四维。
- 相关仓库：与本次查询相关的公开仓库，可 star、可进入。
- 顶部数量用于帮助用户判断结果规模，不提供数量设置。
- 会话页不提供筛选、排序设置和上传入口。


### 6.3.1 对话视图

页面元素：

- 消息列表：系统欢迎、用户问题、助手回答；
- 引用标记：回答中的编号引用；
- 输入框、发送按钮、停止按钮；
- 无证据提示；
- 历史消息滚动。

交互：

- 首次进入显示系统消息，概述本次结果；
- 用户提问后，回答逐步显示；
- 生成中可停止；停止后保留已生成内容；
- 点击引用打开论文详情并尽量定位原文；
- 会话没有证据时输入框不可用；
- 对话只使用本次会话的证据，不重新检索。

#### QA-01 会话内对话

- 范围固定为本次会话保存的论文和证据。
- 支持多轮追问；不引入新的检索工具，不扩大范围。
- 事实性内容必须带引用；没有足够证据时拒答。
- 用户问到会话之外的内容时，说明当前范围不够，建议发起新的全局查询或去相关仓库。
- 对话历史保存，重新打开会话可继续。
- 同一会话的对话属于发起用户；其他用户看不到。
- 不做 Agent 多步检索，不做全局搜索。

### 6.3.2 论文总结视图

页面元素：

- 论文列表：一行一篇；
- 每行显示标题、作者、年份、期刊/会议；
- 每行有“展开四维”和“进入详情”；
- 四维区域：问题、前人研究、方法/创新、不足；
- 详略切换：简要、标准、深入；
- 生成中、失败、信息不足状态。

交互：

- 点击“展开四维”在当前行下方展开，不跳页；
- 点击“进入详情”打开论文详情；
- 展开和进入详情是两个独立动作；
- 切换详略只影响当前论文；
- 展开状态在视图切换后保留；
- 列表不使用多列对比表；一篇论文始终一行。

#### VIEW-01 论文四维总结

- 四维固定为问题、前人研究、方法/创新、不足。
- 四维是论文级内容：同一篇论文在会话、仓库、详情中一致。
- 第一次展开时生成，之后读缓存；默认“标准”。
- 支持简要、标准、深入；切换优先读缓存。
- 四维使用论文自身内容，不受本次会话证据范围限制。
- 信息不足写“论文未明确说明”；可以附同一篇论文的原文证据。
- 点击证据进入详情并尽量定位；定位失败至少打开详情。
- 生成失败显示重试；不阻塞其他论文。
- 不做会话级四维，不做用户级覆盖。
- 归档论文的已生成四维仍然可看。

### 6.3.3 相关仓库视图

页面元素：

- 相关仓库卡片列表；
- 每张卡片：名称、创建者、简介、论文数量、star 数量、推荐理由；
- star/取消 star 按钮；
- 进入仓库按钮；
- 空状态。

交互：

- 只展示公开仓库；
- 排除用户自己的仓库；
- 必须与本次查询相关；star 只能加分；
- 点击卡片进入仓库；
- star 后数量立即更新；
- 没有相关仓库时提示浏览公开仓库。

#### REPO-05 Star 与相关仓库推荐

- 只能 star 公开仓库；不能 star 自己的仓库。
- 一个用户对一个仓库只有一条 star，可取消。
- star 不是收藏夹，不授予额外权限。
- 私有仓库不能 star、不进入推荐；公开转私有后 star 隐藏，转回公开后恢复。
- 相关仓库必须与本次查询、会话论文或仓库标题/简介相关；相关性优先于 star。
- 高 star 但无关的仓库不能出现在推荐里。
- 推荐卡片显示推荐理由，避免用户误解为纯热度排序。


### 6.4 仓库页

仓库页是“论文集合 + 对话”的工作台，左侧是论文，右侧是按需展开的对话。

页面结构：

- **顶部**：返回、仓库名称、公开/私有标识、创建者、论文数量、star 数量（公开仓库）、star 按钮（公开仓库且非创建者）、编辑按钮（创建者；管理员管理私有仓库时也显示）。
- **左侧论文列表**：一行一篇；标题、作者、年份、期刊/会议；展开四维；进入详情；创建者或管理私有仓库的管理员可移除。
- **左侧工具栏**：创建者或管理私有仓库的管理员可见“添加论文”；不提供筛选。
- **右侧对话面板**：默认收起；点击“对话”展开；包含消息、输入、停止、引用。
- **空状态**：仓库没有论文时显示“先添加论文”；没有相关证据时拒答。

交互规则：

- 打开仓库默认只显示论文列表和“对话”按钮，不自动打开聊天。
- 点击“对话”后，右侧半边变为聊天面板；再次点击可收起。
- 聊天面板不显示命中论文列表；引用仍然可点击。
- 论文列表一篇一行；不使用多列卡片。
- 公开仓库的访客可以查看、对话、star；不能编辑。
- 私有仓库只对创建者和管理员显示；普通非创建者看到无权访问。
- 仓库页不提供筛选、排序设置和上传入口。

#### REPO-01 创建与设置仓库

- 任意登录用户可创建仓库；填写名称、简介、公开/私有。
- 仓库归创建者所有；名称在创建者范围内唯一；创建者可以修改名称、简介和可见性。
- 公开仓库：所有登录用户可查看、对话、star；只有创建者能编辑。
- 私有仓库：创建者和管理员可见、可对话；普通用户不可见；不能 star、不推荐。管理员可以编辑私有仓库的信息、增删论文、删除仓库。
- 公开转私有：隐藏集合和 star，不参与推荐；已有 star 记录保留，转回公开恢复展示。私有转公开后，管理员回到只读，编辑权归创建者。
- 创建者可以删除仓库；管理员可以删除私有仓库。删除集合、仓库对话和 star 关系，不删除全局论文。
- V1.0 不做成员邀请和多人协作。

#### REPO-02 从全局目录添加/移除论文

- 只能从全局论文目录添加论文，不能上传。
- 添加弹窗支持按标题/关键词搜索全局目录，多选加入；创建者和管理私有仓库的管理员可以使用。
- 只显示已就绪论文；处理中和已归档论文不能新加入。
- 重复添加直接忽略，不产生重复。
- 创建者可以移除论文；管理员管理私有仓库时也可以。移除只影响仓库，不删除全局论文。
- 移除后，仓库的新对话不再使用这篇论文；已有消息保留，引用仍可打开全局详情。
- 不设仓库论文数量上限。
- 空仓库显示添加论文入口。

#### REPO-03 仓库页面与论文列表

- 顶部信息完整展示名称、简介、创建者、可见性、论文数量、star 数量（公开仓库）。
- star 按钮只对公开仓库且非创建者显示。
- 编辑和删除对创建者显示；管理员在私有仓库显示管理入口，在公开仓库只读。
- 论文列表一行一篇，可展开四维，可进入详情。
- 创建者可以添加和移除论文；管理员管理私有仓库时也可以；访客只读。
- 右侧对话默认收起，点击后展开；不自动占用页面。
- 私有仓库对普通非创建者不泄露名称、数量、论文或对话；管理员可进入管理。
- 公开仓库的访客对话不向创建者和其他用户展示；私有仓库对话创建者和管理员可见。

#### REPO-04 仓库对话与只读 Agent

- 范围是整个当前仓库，所有仓库论文都可被检索。
- Agent 可以多步查找、比较和汇总，但只在仓库内检索。
- 不允许访问全局目录、其他仓库、互联网或外部工具。
- 不允许新增、修改、删除任何数据。
- 回答必须带引用；引用点击打开论文详情并尽量定位原文。
- 不显示命中论文列表；论文列表始终在左侧。
- 没有证据时明确拒答，并建议换问法或添加论文。
- 空仓库不能对话。
- 公开仓库对话只属于发起者；私有仓库对话创建者和管理员可见。
- 不做仓库级四维；需要领域总结时使用仓库对话。


### 6.5 论文详情

页面结构：

- 顶部：返回来源、标题、作者、年份、期刊/会议、下载按钮；
- 元数据区：摘要、DOI/来源标识、归档标识；
- 四维区：问题、前人研究、方法/创新、不足；可切换简要/标准/深入；
- 原文区：原文预览或下载入口；引用定位时尽量高亮；
- 单篇对话区：入口或右侧面板。

交互：

- 所有登录用户都可以打开全局目录论文的详情，不管它是否在私有仓库。
- 下载只在有原文文件时可用。
- 四维按需生成；失败可重试。
- 从会话/仓库/四维引用进入时，尽量定位并高亮；失败时打开详情顶部。
- 单篇对话只围绕当前论文。
- 归档论文可被旧会话/旧仓库打开，显示归档标识。

#### VIEW-02 论文详情与下载

- 展示标题、作者、年份、期刊/会议、摘要、四维和下载入口。
- 论文的全局可见性不受仓库私有性影响。
- 没有原文文件时提示不可下载。
- 引用定位失败不伪造位置。
- 详情页不提供上传、元数据编辑或加入仓库；这些属于管理员和仓库创建者。
- 归档论文的可下载性由文件是否保留决定；旧引用不因归档失效。

#### QA-02 单篇论文对话

- 只使用当前论文的内容。
- 不访问全局目录、其他论文或仓库。
- 支持多轮追问；事实性内容带引用。
- 没有证据时拒答，建议换问法或查看四维。
- 对话历史按用户和论文保存。
- 不能从单篇对话直接加入仓库或触发全局搜索。

### 6.6 管理后台

管理后台是管理员的工作区，不是普通用户入口。

页面结构：

- 左侧导航：总览、论文目录、仓库管理、用户管理；
- 顶部：返回主页、当前管理员、退出；
- 总览：论文、就绪、处理中、失败、仓库（含私有）、用户数量；快捷入口；
- 论文目录：导入按钮、论文列表、状态、元数据编辑、重试、归档；
- 仓库管理：所有仓库列表（含私有），显示名称、创建者、可见性、论文数、star 数、更新时间；可进入私有仓库查看集合和对话、编辑、删除；公开仓库只读；
- 用户管理：用户列表、创建、角色、停用、重置密码。

交互规则：

- 只有管理员可以进入。
- 管理员可以导入和维护全局论文目录；可以查看和管理私有仓库；对公开仓库只读，不编辑其内容。
- 公开仓库的访客对话仍只属于发起者，管理员不因管理私有仓库而获得公开仓库对话内容。
- 不做评测、审计、运营报表、部署和监控入口。
- 论文删除优先使用归档，避免旧会话引用断裂。

#### AUTH-04 用户管理

- 管理员创建普通用户或管理员账号。
- 可以修改显示名和角色。
- 可以停用账号；停用后不能登录，历史记录保留。
- 可以重置密码；不提供自注册和自助找回。
- 不删除用户，不做审计日志。

#### KB-01 管理员导入论文

- 只有管理员能导入 PDF。
- 导入进入全局目录，不直接进入仓库。
- 本期只处理带文本层的 PDF，只读取文字层；本期不做图片和 Word：图片型 PDF、扫描件、截图不解析，不做 OCR；Word 不在范围。
- 支持多文件；单文件失败不影响其他文件。
- 重复论文复用已有目录记录。
- 导入后显示处理状态；就绪后可被全局搜索。

#### KB-02 解析、索引与失败重试

- 处理状态：排队、解析、索引、就绪、失败。
- 提取标题、作者、年份、期刊/会议、摘要等元数据，并建立原文索引。
- 处理中论文不出现在搜索结果；就绪后进入全局目录。
- 失败显示原因，可单篇重试。
- 解析质量不足时允许修正元数据或重新导入；不承诺图片、扫描件和复杂版式。

#### KB-03 论文目录维护

- 管理员可以按标题搜索目录，查看状态和元数据。
- 可以修正标题、作者、年份、期刊/会议、摘要。
- 可以归档论文；归档后不再出现在新搜索和新仓库添加中。
- 旧会话和旧仓库中的归档论文仍可打开、引用；原文文件保留时仍可下载。
- 默认归档而不是物理删除；不做版本历史和审计日志。

#### ADM-01 管理总览与仓库管理

- 展示论文总数、就绪数、处理中/失败数、仓库数（含私有）、用户数。
- 提供导入、论文目录、仓库管理、用户管理快捷入口。
- 不展示评测、审计、运营图表。
- 管理员可以查看和管理私有仓库；不能编辑公开仓库。


## 7 核心流程

### 7.1 全局查询到会话

```text
用户在主页输入 query
→ 系统在全局论文目录检索
→ 组织相关论文和原文证据
→ 创建会话（保存证据快照）
→ 自动进入会话工作区
→ 默认“对话”，可切“论文总结”“相关仓库”
```

失败分支：

```text
没有证据
→ 创建空会话
→ 显示“没有找到足够证据”
→ 不允许对话
→ 修改查询 / 去仓库看看
```

### 7.2 PDF 查询

```text
用户选择 PDF
→ 提取文字
→ 文字作为本次 query
→ 进入全局检索
→ 不保存 PDF、不入库、不进仓库
```

无法读取：

```text
PDF 无文本层或读取失败
→ 停留主页
→ 提示改用文字查询
→ 不做图片识别，也不调用 OCR
```

### 7.3 会话内切换

```text
进入会话
→ 默认对话
→ 切换论文总结：展开任意论文四维
→ 切换相关仓库：star 或进入仓库
→ 切回对话：消息和输入保留
```

切换不重新检索、不改变证据快照、不丢失展开状态。

### 7.4 创建仓库并添加论文

```text
登录用户创建仓库（主页或会话页）
→ 填写名称、简介、公开/私有
→ 可选：把本次会话的论文带入新仓库
→ 打开仓库
→ 点击“添加论文”
→ 搜索全局目录
→ 多选添加
→ 左侧论文列表更新
```

规则：

- 不能上传；
- 重复添加忽略；
- 已归档/处理中论文不能新加入；
- 创建者可以移除论文；
- 移除不影响全局论文。

### 7.5 仓库对话

```text
用户打开仓库
→ 点击“对话”展开右侧面板
→ 在仓库范围内检索
→ Agent 可多步查找/比较
→ 回答 + 引用
→ 点击引用打开论文详情
```

边界：

- 只在当前仓库；
- 只读，不写；
- 不访问全局目录、其他仓库、互联网；
- 没有证据拒答；
- 空仓库不能对话；
- 不显示命中论文列表。

### 7.6 四维生成与缓存

```text
用户展开某篇论文的四维
→ 检查该论文 + 当前详略 + 版本的缓存
→ 有缓存：直接显示
→ 无缓存：生成 → 保存 → 显示
→ 切换详略：重复上述检查
→ 生成失败：显示重试
```

关键点：

- 四维属于论文，不属于会话；
- 同一篇论文在不同页面看到同一份内容；
- 四维使用论文自身内容，不受会话证据范围限制；
- 不做用户级覆盖，不做会话级四维。

### 7.7 单篇对话

```text
用户进入论文详情
→ 打开单篇对话
→ 只在这篇论文内检索
→ 回答 + 引用
→ 点击引用定位原文
```

没有证据时拒答；不能访问其他论文。

### 7.8 Star 与推荐

```text
用户在公开仓库点击 star
→ 记录用户-仓库关系
→ star 数量更新
→ 相关仓库推荐把 star 作为加分项
→ 但仍先判断相关性
```

规则：

- 不能 star 自己的仓库；
- 私有仓库不展示 star、不推荐；
- 高 star 但无关的仓库不进入推荐；
- 推荐卡片给出理由。

### 7.9 管理员导入

```text
管理员进入后台
→ 上传 PDF
→ 查看处理状态
→ 失败重试 / 修正元数据
→ 论文就绪
→ 进入全局目录
→ 用户可搜索
```

管理员导入不选择仓库；论文归属全局目录。用户添加论文是“引用”，不是复制。

### 7.10 管理员管理私有仓库

```text
管理员进入后台
→ 仓库管理
→ 选定私有仓库
→ 查看论文集合与对话
→ 编辑信息 / 增删论文 / 删除仓库
```

管理员的管理权限只覆盖私有仓库；公开仓库在后台只读。私有仓库转为公开后，管理员立即回到只读。

## 8 状态与空态

| 场景 | 页面 | 用户看到 | 可以做什么 |
| :--- | :--- | :--- | :--- |
| 未登录 | 业务页面 | 回到登录页 | 登录 |
| 登录失败 | 登录页 | 邮箱或密码错误 | 重试 |
| 全局目录为空 | 主页 | 暂无论文 | 联系管理员 |
| 查询无结果 | 会话 | 没有找到足够证据 | 修改查询、去仓库 |
| PDF 无文本 | 主页 | 无法读取 PDF 文字 | 改用文字查询 |
| 论文处理中 | 后台/搜索 | 处理中，不进入结果 | 等待或重试 |
| 论文处理失败 | 后台 | 失败原因 | 重试、修正、重新导入 |
| 会话无证据 | 会话 | 三个视图空状态 | 修改查询、去仓库 |
| 仓库为空 | 仓库页 | 先添加论文 | 添加论文 |
| 仓库无相关证据 | 仓库对话 | 没有足够证据 | 换问法、添加论文 |
| 四维生成中 | 论文行/详情 | 加载状态 | 等待 |
| 四维失败 | 论文行/详情 | 生成失败 | 重试 |
| 四维信息不足 | 四维区域 | 论文未明确说明 | 查看原文 |
| 单篇无证据 | 单篇对话 | 没有足够证据 | 换问法、看四维 |
| 无相关仓库 | 会话相关仓库 | 暂无相关仓库 | 浏览公开仓库 |
| 普通用户无权限看私有仓库 | 仓库页 | 无权访问 | 返回 |
| 论文已归档 | 详情/列表 | 已归档标识 | 继续阅读旧引用 |
| 模型不可用 | 对话/生成 | 暂时无法生成 | 稍后重试 |

页面状态要求：

- 加载状态不能阻塞整个页面，至少保留导航和已加载内容。
- 错误信息用用户能理解的语言，不展示内部错误码和堆栈。
- 空状态必须给出下一步，不只显示“暂无数据”。
- 危险操作（删除仓库、移除论文、归档）需要确认。
- 列表支持分页或加载更多；本期不提供筛选。


## 9 关键规则与边界案例

### 9.1 全局目录与仓库

| 问题 | 答案 |
| :--- | :--- |
| 私有仓库里的论文，别人能全局搜到吗？ | 能。私有对普通用户只隐藏集合和对话，不隐藏论文。 |
| 用户能把 PDF 上传到仓库吗？ | 不能。仓库只能从全局目录添加论文。 |
| 管理员导入论文时要选仓库吗？ | 不选。论文进入全局目录；用户之后可以引用到自己的仓库。 |
| 删除仓库会删除论文吗？ | 不会。只删除集合、仓库对话和 star 关系。 |
| 归档论文会破坏旧会话吗？ | 不会。旧会话和旧仓库仍可打开、引用；原文文件保留时仍可下载。 |

### 9.2 私有与管理员

- 私有仓库只有创建者和管理员能查看论文集合与对话；普通用户不能。
- 管理员可以管理私有仓库的信息、论文、对话和删除；对公开仓库只读。
- 公开仓库的编辑权只属于创建者；管理员没有公开仓库编辑权。
- 公开仓库的访客对话只属于发起者，不向创建者或其他用户展示；私有仓库对话创建者和管理员可见。
- 私有仓库不能 star；公开转私有后 star 隐藏，转回公开后恢复。
- 私有转公开后，管理员立即回到只读，编辑权归创建者。

### 9.3 会话快照

- 会话保存创建时的论文和证据；后续全局目录变化不修改旧会话。
- 旧会话中的论文即使被移出某个仓库，仍可打开详情和引用。
- 旧会话中的论文被归档后，仍可打开和下载（文件保留时）。
- 会话不因为重新打开而重新检索。

### 9.4 四维缓存

- 缓存键由论文、详略和内容/模型版本决定。
- 同一篇论文在会话、仓库、详情使用同一份四维。
- 用户不能编辑四维；没有用户级覆盖。
- 论文内容或生成版本变化时，旧缓存失效。
- 归档论文的已生成四维仍可查看。
- 四维失败不影响会话、仓库和论文详情的主体内容。

### 9.5 Star

- star 只对公开仓库开放。
- 不能 star 自己的仓库。
- 一个用户对一个仓库最多一个 star，可取消。
- star 不授予额外权限；公开仓库本来就可读。
- 私有仓库不展示 star，不参与推荐。
- 推荐先看相关性，再看 star；star 不能单独把无关仓库推上来。

### 9.6 数量与范围

- V1.0 不设全局论文数量、仓库容量、会话论文数、证据数、每轮证据数、检索档位或检索次数上限。
- 列表使用分页/加载更多，这是界面机制，不是产品数量上限。
- 系统根据相关性和可用上下文组织结果；后续版本可以再引入范围档位和配额。

### 9.7 安全与隐私

- 所有业务页面需要登录。
- 私有仓库对普通非创建者不泄露名称、数量、论文、star 或对话；管理员因管理需要可见。
- 回答不展示系统提示、内部字段或模型配置。
- 用户不能上传论文或文件；本期只处理管理员导入的 PDF。
- 本期不做多租户、审计、分享链接和公开接口。

## 10 本期不做与后续扩展

### 10.1 本期不做

- 自动评测、指标看板、课程验收评测；
- SSO、LDAP、TOTP、自注册、多因素认证；
- 审计日志、导出、移动端；
- 部署、容器化、监控、压测。

### 10.2 后续扩展

## 11 术语表

| 术语 | 含义 |
| :--- | :--- |
| 全局论文目录 | 管理员导入的全部论文，是搜索的唯一来源 |
| 仓库 | 用户从全局目录挑选的论文集合，公开或私有 |
| 会话 | 一次全局查询产生的论文、证据和对话空间 |
| 证据 | 用于回答和引用的原文片段 |
| 四维 | 问题、前人研究、方法/创新、不足 |
| RAG | 先检索证据，再基于证据生成回答 |
| Agent | 在仓库范围内只读检索和多步整理的助手 |
| Star | 对公开仓库的推荐信号，不是收藏 |
| 会话快照 | 会话创建时保存的论文和证据，不随全局目录变化 |
| 详略 | 四维总结的简要、标准、深入三种展开程度 |

## 12 给实现者的最短路径

如果由 AI 或其他开发者实现，按下面顺序保证主链路：

1. 登录、角色和全局论文目录；
2. 管理员导入 PDF、处理状态和元数据；
3. 主页文字/PDF 查询、全局检索、会话创建；
4. 会话三视图、四维懒生成与缓存；
5. 论文详情、下载、单篇对话；
6. 仓库创建、从全局目录添加论文、仓库页；
7. 仓库只读 Agent、引用和拒答；
8. Star 与相关仓库推荐；
9. 管理总览、仓库管理和用户管理。

无论实现顺序如何，下面几条不能省：

- 全局目录与仓库分离；
- 私有仓库对普通用户只隐藏集合和对话，不隐藏论文；管理员可管理私有仓库；
- 首页 PDF 只查询，不入库；
- 四维是论文级共享缓存，不做会话级四维；
- 三种对话范围严格隔离；
- 回答必须有引用，没有证据必须拒答；
- 不设本期数量上限；
- 不做用户上传和论文筛选。

## 13 一句话总结

**管理员维护全局论文目录、账号和私有仓库，用户用一次查询生成会话，在会话里读论文总结和相关仓库，在自己的仓库里做有边界的对话，在单篇论文里精读和追问；所有回答都能回到原文，所有范围都不越界。**
