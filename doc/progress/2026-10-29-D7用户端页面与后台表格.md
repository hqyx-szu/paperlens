## D7.1 后台论文表格可读性修复

**问题**：长标题（中英文混排、无空格）在 `web/admin/index.html` 的论文表里遇到 `word-break: break-word`
与窄列，逐字竖排换行，单行被撑到数百像素，一屏只能看两三篇。

**改动**（只动 `web/admin/index.html`，接口不变）：

| 项 | 做法 |
| --- | --- |
| 表格布局 | 论文表加 `.papers-table { table-layout: fixed; }`，列宽固定、可预测 |
| 标题 | `.cell-clamp-2`：`-webkit-line-clamp: 2` 两行截断 + `title="完整标题"` 悬停显示全文 |
| 作者/年份 | 同样两行截断 + 悬停全文 |
| 文件名 | 单行 `text-overflow: ellipsis` + 悬停全文 |
| 徽章 | 状态/归档列加 `white-space: nowrap`，并按文字宽度给足列宽（96 / 86px），不再竖排 |
| 密度 | 表格内边距 12/18 → 10/12，列宽重分配（作者 118、文件名 120、时间 122、操作 236） |
| 导入结果 | `#importItems` 限高 160px 滚动、`word-break: break-all`，长文件名不再撑高卡片 |

用户端 `/app` 的论文卡片与相关仓库名称同样加了 2 行截断 + `title` 悬停。

**浏览器实测**（5 篇论文，含 160 字符英文长标题、归档、失败、处理中）：

```
行高：53 / 55 / 59 / 52 / 52 px（修复前长标题行 > 200px）
归档列：未归档 / 未归档 / 已归档 / 未归档 / 未归档（单行）
状态列：解析中 / 失败 / 就绪 / 就绪 / 就绪（单行）
标题：两行截断，悬停可见完整标题（title 属性）
```

**验证**：`pytest -q tests/api/test_admin_ui.py tests/api/test_user_ui.py` → 6 passed；
静态页断言（无外链、关键文案）保持不变。
