### E1 管理后台「仓库」页签

- `web/admin/index.html` 顶部新增 `data-view="repos"` 页签；`switchView()` 白名单加 `repos`，
  `refresh()` 改为 `loaders` 映射（users/papers/repos）。
- 列表列：ID、名称（两行截断 + 悬停）、可见性徽章、创建者、邮箱（单行省略 + 悬停）、论文数、star、
  更新时间、操作；工具条支持 `q`（仓库名/创建者邮箱/显示名）与 `visibility` 过滤，带分页与空态。
- 概览行显示 `共 N 个仓库 · 全站私有 M 个`（`stats.repos_total` / `stats.repos_private`）。
- 公开仓库操作列显示「只读」并带 `title="公开仓库仅创建者可在用户端管理"`，私有仓库显示「管理」。
- 实测：`共 2 个仓库 · 全站私有 1 个`；公开行 `只读`、私有行 `管理`；切 tab 后概览数字同步刷新。

### E2 私有仓库管理面板

- `repoDialog`：元信息（创建者/可见性/论文数/star/权限）+ 名称/可见性/简介（两列紧凑表单）+
  保存/删除/关闭 + 「论文」「对话」两个子页签。
- 论文：`GET /repos/{id}/papers?page_size=100` 列表（标题两行截断、归档标记）、「添加论文」选择器
  （`GET /papers?status=ready&archived=false`，多选 → `POST /repos/{id}/papers`，toast 显示
  加入 N 篇 / 忽略 M 篇）、「移出」（`DELETE /repos/{id}/papers/{paper_id}`）。
- 对话：`GET /repos/{id}/conversations?page_size=50` 左栏列表（发起者/消息数/最后消息时间），
  点击右栏 `GET /repos/{id}/conversations/{cid}/messages?limit=100` 只读展示（system/user/assistant 配色，
  带引用条数与状态）。
- 权限：面板只在 `can_edit && can_delete && can_manage_papers` 时可写；改可见性为公开后自动关闭面板并提示
  「管理员不再有管理权限」（实测 toast + 列表变只读）。
- 删除：二次确认（提示会连带删除该仓库全部对话），成功后关闭面板并刷新列表（实测 2 → 1 个仓库）。

### E3 用户端论文详情 `#/papers/{id}`

- 新增 `paperView` 分区与路由 `#/papers/{id}(?page=&quote=)`；`hideViews` 纳入，`showHome` 重置标题与
  `currentPaper`。
- 内容：标题、作者/年份/venue/DOI/在架状态、摘要（限高滚动）、下载原文（`has_file && can_download`）、
  四维总结（brief/standard/deep 切换，未生成时提示并给「生成总结」，命中缓存直接渲染）、单篇对话
  （SSE + 历史 + 停止）。
- 会话/仓库里的论文卡整卡可点（按钮区域除外）进入详情，`paperReturnHash` 记录来源，
  「← 返回」回到原页面（实测 `#/papers/173` → 返回 `#/sessions/45`）。
- `can_chat=false`（无片段/未就绪）时输入框与发送按钮禁用并给出原因；实测种子论文（无片段）正确禁用。

### E4 引用 → 论文定位

- 引用弹窗新增「打开论文」：跳 `#/papers/{paper_id}?page=N&quote=…`（`encodeURIComponent` 由
  `URLSearchParams` 处理）。
- 详情页顶部定位条：`引用定位：第 N 页` + 引用摘录 + 明确说明「只展示摘录与页码，不渲染 PDF 页面」。
- 实测：`showCitation({page:3, quote:'本文提出 Transformer…'})` → 打开论文 → hash
  `#/papers/173?page=3&quote=…`，定位条三行文案正确。

### E5 收尾

- 空态/错误态：论文不存在 → 标题「论文打不开」+ 错误文案；无对话 → 「还没有关于这篇论文的对话」；
  无总结 → 「还没有「标准」版总结，点「生成总结」」；选择器无候选 → 「没有可添加的论文」；
  对话列表空 → 「还没有用户在这个仓库里对话」；消息区空提示「点左侧对话查看消息」。
- 静态页测试新增 4 项：后台仓库页签与管理面板、用户端论文详情视图、引用跳转与三档总结
  （仍断言无外链资源）。
- 修复的两个真实 bug（浏览器实测发现）：
  1. 全局 `input { width: 100% }` 把选择器里的复选框撑满整行 → 标题被压成竖排；用
     `.repo-admin-item input[type="checkbox"]` 复位。
  2. 仓库管理面板 `paper-meta` 的多行文本未生效（缺 `white-space: pre-line`）；同时把表单改为两列、
     对话改为左列表右消息两栏，避免弹窗内容过长。
- README 新增「页面地图」（`/admin`、`/app` 及 5 条 hash 路由），说明管理员对公开仓库只读。
