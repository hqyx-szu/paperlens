## M1 深链别名（`app/main.py`）

- 新增 5 条页面别名路由（全部 `include_in_schema=False`，307 跳转）：
  - `/sessions/{session_id:int}` → `/app#/sessions/{id}`
  - `/repos/{repo_id:int}` → `/app#/repos/{id}`
  - `/papers/{paper_id:int}` → `/app#/papers/{id}`
  - `/admin/{overview|papers|repos|users}` → `/admin#/{view}`
- 用显式 int/枚举路由而不是 catch-all：`/api/v1/*`、`/docs`、静态页不受影响
  （`test_alias_does_not_shadow_api` 断言 `/api/v1/papers` 仍是 401 JSON）。
- 非整数 id（`/papers/abc`）不匹配别名 → 404，不会误跳页面（有测试）。
- `test_openapi_still_matches_contract` 把运行期 `app.openapi()` 与 `doc/paperlens-openapi.json`
  逐 path+method 比对：仍为 **46/46，零多零缺**。

## M2 后台导航与总览（`web/admin/index.html`）

- 顶部页签改为**左侧导航**：总览 / 论文目录 / 仓库管理 / 用户管理（`.admin-shell` + `.side-nav`），
  小屏折叠为横向滚动条。
- 新增总览页 `#overviewView`：9 张卡片（用户总数、启用用户、论文总数、就绪、处理中、失败、已归档、
  仓库总数、私有仓库），全部来自 `GET /admin/stats`，并显示统计时间。
- 4 个快捷入口：导入论文（切到论文目录并直接唤起文件选择）、论文目录、仓库管理、用户管理。
- 视图与 hash 双向同步：切页签写 `#/view`（`history.replaceState`，不产生额外历史），
  加载时按 hash 决定初始视图；`hashchange` 支持浏览器前进/后退与手改 URL。
- 头部加「用户端」入口，方便管理员跳去前台验证。
- 实测（真实 `/admin/stats`）：`2 / 2 / 4 / 2 / 1 / 0 / 0 / 3 / 1`，与接口逐项一致。

## M3 用户端导航与主页面板（`web/app/index.html`）

- 顶部导航：首页 / 我的仓库 / **管理后台（仅 admin）** / 退出；`#userBadge` 显示角色，悬停显示
  `显示名 <邮箱>`。reader 登录时管理入口保持隐藏（实测 `adminEntryHidden: true`）。
- 主页新增两个面板：「我的仓库」「公开仓库」，各取 `GET /repos?scope=mine|public&page_size=5`，
  卡片复用仓库卡片（点击进仓库页），空态与错误分别在面板内提示，另有「查看全部 →」。
- 实测：reader 的「我的仓库」= 公开+私有各一条；「公开仓库」= 管理员公开库 + 自己的公开库
  （契约：`scope=public` 含自己的公开仓库）。

## M4 仓库页双栏（`web/app/index.html`）

- 布局按 §4.2 改为 `.repo-workspace` 两栏：左论文列表、右对话面板；`#repoChatToggle` 收起/展开，
  收起后论文列表占满整行；宽度 ≤960px 自动单列。
- 旧的页签切换函数保留为兼容层（`switchRepoTab`），进入仓库时确保两栏都可见且对话未折叠。
- 实测：1440 宽下 `580.8px 475.2px` 两栏；点「收起」→ `1072px` 单栏、对话不可见、按钮变「展开对话」。
- `setStreaming()` 的 paper/repo/session 三分支不受影响（`repoSendButton` 等 id 未改）。

## M5 引用定位增强与收尾

- 定位条：页码 + `<mark>` 高亮摘录（浅黄底）+ 「复制摘录」按钮（`navigator.clipboard`，
  非安全上下文失败时提示手动选择）+ 明确说明「不渲染 PDF 页面本身」。
- 实测：`#/papers/1?page=4&quote=…` → 定位条三行 + `<mark>` 背景 `rgb(253,230,138)` + 复制按钮。
- 静态页测试新增：后台侧栏 4 项、9 个统计卡 id、4 个快捷入口；用户端管理入口、主页两面板、
  仓库双栏与收起、定位条高亮与复制。全部保持「无外链资源」断言。

## 已知边界（不属于 P0）

- 引用定位只给页码 + 摘录，不渲染 PDF 页面（需要引入 pdf.js，属于新依赖，未做）。
- 零构建页面仍是单文件 HTML（无组件化/路由库）；若要交接给前端团队可另起 React 版本。
- 文档明确不做的：自动评测、审计日志、运营报表、部署与监控入口。
- 演示前需要管理员在 `/admin` 导入真实 PDF；历史论文可跑 `uv run python -m scripts.embed_chunks` 补向量。
